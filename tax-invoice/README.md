# 세금계산서 미처리현황 · 회계 월마감

미처리 세금계산서를 현업에 공유할 때, **예상담당자**를 자동으로 붙입니다.

## 판정 순서

1. **1순위 이메일**
   - 매입세금계산서: `공급받는자이메일`
   - 매출세금계산서: `공급자이메일` (공급하는자 이메일)
2. **2순위 과거 처리**
   - 1순위 메일이 없거나, 아래 매핑에 없으면
   - 거래처 **사업자번호** → 없으면 **거래처명**(주식회사/(주) 제거)으로 과거 처리 데이터를 찾음
   - 담당자가 여러 명이면 **처리 건수가 많은 사람**, 같으면 **최근 처리일**

### 이메일 매핑

| 이메일 | 예상담당자 |
| --- | --- |
| fatec@atecomputer.kr | 남부,중부사업부 |
| eatec@atecomputer.kr | 이은정(교육,전자칠판) |
| tatec@ateccomputer.kr | 강소라(공공,수도권) |

`tatec@atecomputer.kr` 도 강소라로 동일 처리합니다.

## 사용

1. **`세금계산서_미처리현황.html`** 을 브라우저로 엽니다. 샘플 18건이 바로 보입니다. 이 파일 하나만 있으면 됩니다.
2. 실제 마감 시
   - **세금계산서 미처리현황** 엑셀
   - **과거 처리 데이터** 엑셀
   을 각각 올립니다.
3. 담당자 카드를 눌러 필터하고, **공유 문구 복사** 또는 **엑셀 내려받기**로 현업에 전달합니다.

샘플 파일:

- `data/세금계산서_미처리현황_샘플.xlsx`
- `data/과거_처리데이터_샘플.xlsx`

샘플을 다시 만들려면:

```bash
python3 tax-invoice/scripts/generate_sample.py
```

## 엑셀 컬럼

미처리현황에 있으면 좋은 컬럼:

`구분, 승인번호, 작성일자, 공급자등록번호, 공급자상호, 공급자이메일, 공급받는자등록번호, 공급받는자상호, 공급받는자이메일, 품목, 공급가액, 세액, 합계금액, 비고`

과거 처리 데이터:

`처리일자, 구분, 거래처사업자번호, 거래처명, 품목, 공급가액, 처리담당자, 처리부서`

컬럼명에 공백이 있거나 `공급하는자이메일`, `처리자`처럼 달라도 읽도록 맞춰 두었습니다.
